## 4. Important Inconsistencies Corrected

1. **Computational Profiling Telemetry Reconciled**:
   - In preliminary drafts, task rows were shifted (e.g., Category Logistic Regression latency of 143.2 $\mu$s was mistakenly placed in Binary Logistic Regression; Binary LightGBM was listed as 1,409.8 $\mu$s instead of 1,983.3 $\mu$s; Random Forest latencies were transposed).
   - *Correction*: All 15 primary configurations across SGD, PyTorch MLP, LightGBM, XGBoost, and Random Forest were cell-by-cell reconciled against [`results_v2/tables/centralized_experiment_ledger.csv`](../results_v2/tables/centralized_experiment_ledger.csv) and binary model files in [`models/active/`](../models/active/).
2. **Strategy 2 Purged Population Arithmetic Corrected**:
   - `data/README.md` and early Stage 1/2 notes listed Strategy 2 as purging 54,828 rows.
   - *Correction*: Verified that 54,828 was a pre-audit count. The 8,740 conflicting collision hashes account for exactly 18,416 rows in the unique stratum ($N=501,098$). Purging them leaves exactly 482,682 flows ($501,098 - 18,416 = 482,682$, partitioned into Train: 337,838; Val: 72,390; Test: 72,454).
3. **Cross-Capture Binary MCC Values Corrected**:
   - In preliminary drafts, cross-capture MCC values were approximated (e.g., LightGBM MCC listed as 0.4912 instead of 0.5189; Random Forest listed as 0.4850 instead of 0.5245).
   - *Correction*: Reconciled to the exact figures recorded in [`results_v2/tables/stage4_test_results.csv`](../results_v2/tables/stage4_test_results.csv).
4. **Leakage, Collision Taxonomy, and Overlap Terminology Calibrated**:
   - Preliminary drafts occasionally conflated observed feature overlap with proven classifier lookup reliance.
   - *Correction*: Clarified that feature overlap creates an empirical opportunity or potential for coordinate memorization rather than definitive proof of classifier reliance. Replaced unverified claims (such as 48.2% benign entanglement) with exact ground-truth collision counts: 96.49% of all 8,740 collision hashes (8,433 hashes, 26,697 flows; 93.32% of collision flows) are DoS vs DDoS floods, while benign collisions comprise only 41 hashes (0.47%) and 621 flows (0.11% of the dataset). Framed IP/timestamp exclusion as a hypothesized contributing factor to flood collisions.
5. **Computational Profiling Methodology & Measurement Distinctions**:
   - Clarified the distinction between sequential unbatched single-flow latency (P50/P95) and vectorized in-memory batch throughput (which amortizes Python/framework dispatch overhead and does not represent single-flow latency or network interface line rate).
6. **Prevalence Shift Calibration**:
   - Replaced the assertion that cross-capture Macro-F1 improvement was an "artifact of class prevalence shift" with the calibrated finding that it was "partly associated with changes in class prevalence and support between capture sessions."
7. **Removal of Hyperbolic Language & Unsubstantiated Claims**:
   - Removed claims of "wire-speed packet scrubbing", GBDTs being "inherently robust to noise", and microcontroller line-rate guarantees.
   - Replaced promotional phrases ("This confirms ... the true difficulty", "realistic diagnostic baselines", "frequently report ... consistently spanning 98.5% to 99.9%") with calibrated, evidence-bounded scientific phrasing.
