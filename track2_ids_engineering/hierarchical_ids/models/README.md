# Hierarchical IDS Checkpoints (`track2_ids_engineering/hierarchical_ids/models/`)

The 18 serialized `.joblib` model checkpoints generated by [`train_and_tune_val.py`](../experiments/train_and_tune_val.py) (~150 MB total) are intentionally gitignored via `*.joblib` in [`.gitignore`](../../../.gitignore).

To regenerate all Stage 2, Stage 3A/3B, E3 MetaGate, and E4 checkpoints locally from Train/Val:

```powershell
.\.venv\Scripts\python.exe -u -m track2_ids_engineering.hierarchical_ids.experiments.train_and_tune_val --phase all
```
