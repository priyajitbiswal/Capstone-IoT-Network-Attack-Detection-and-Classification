# Stage 4 Final Evaluation Report: Test Generalization & Cross-Capture Robustness

---

## 1. Executive Summary

This report documents the final, strictly read-only evaluation of all 21 models from the CICIoT2023 intrusion detection suite. Every model checkpoint was evaluated across two independent, fully sealed test partitions:
1. **Internal Test Partition ($N = 75,105$)**: Evaluates in-distribution test generalization against 0-leakage held-out samples.
2. **Cross-Capture Clean Test Partition ($N = 57,280$)**: Evaluates out-of-distribution (OOD) robustness across separate, later PCAP capture sessions (`Merged26.csv`–`Merged40.csv`) with zero vector overlap.

All evaluations applied the pre-fitted training preprocessors (`preprocessor_strategy1.joblib` and `preprocessor_strategy2.joblib`) with zero retraining, parameter tuning, or post-hoc threshold adjustment.

### Key Scientific Takeaways:
- **Generalization Invariance**: On the internal test set, all models track their validation performance within $|\Delta| < 0.005$, confirming that no overfitting occurred during training.
- **Domain Shift Resistance**: On cross-capture evaluation, tree models demonstrate superior domain stability compared to linear and MLP baselines, though minority web-attack classes (Tier 4) experience severe domain transfer degradation across all architectures.
- **Overall Champion**: `fine_grained_lightgbm` and `ablation_s2_fine_grained_lightgbm` achieve the highest Macro-F1 across both in-distribution and cross-capture test partitions.
